# 🚀 Space Shooting Game using Python 🛸

A 2D space shooter game built with Python's `turtle` graphics module. In this game, you play as an astronaut defending Earth from alien invaders. Dodge enemies, fire missiles, and survive the invasion!

---

## 🎮 Game Features

- Smooth player movement with `turtle`
- Health bars for both player and enemies
- Ammo tracking with multiple missiles
- Dynamic enemy and boss spawns
- Animated background with moving stars
- Sound effects using `winsound`
- Victory and Game Over conditions

## 🛠 Requirements

- **Python 3.8+**
- Works only on **Windows** (because of `winsound`)
- No external libraries needed except standard modules

Install `pygame` only if you're modifying it with advanced sound or graphics (not required for current version).
